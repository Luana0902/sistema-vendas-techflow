Sistema de Vendas - TechVarejo Solutions
Descrição
Sistema desktop desenvolvido para realizar o controle de vendas de uma loja de varejo.

O sistema permite o gerenciamento de usuários, clientes, produtos e vendas.

Funcionalidades
Login de usuário
Cadastro de usuários
Cadastro de clientes
Cadastro de produtos
Registro de vendas
Cálculo do valor das vendas
Armazenamento dos dados
Como executar
Abra a pasta do projeto no VS Code.
Abra o terminal.
Ative o ambiente virtual, se necessário.
Execute o comando:
python main.py

Faça o login no sistema.
Utilize o menu para acessar as funcionalidades.
Tecnologias utilizadas
Python
PyQt
MySQL
Git
GitHub
